Ready or Not PvP - SWAT против подозреваемых (АЛЬФА-ВЕРСИЯ)
=========================================================

Это альфа-версия: возможны ошибки и вылеты. Пожалуйста, сообщайте о них:
https://github.com/VolkovIlia/ReadyOrNot-PvP/issues
Приложите файлы с компьютера хоста:
  <папка игры>\ReadyOrNot\Binaries\Win64\ue4ss\UE4SS.log
  <папка игры>\ReadyOrNot\Binaries\Win64\ue4ss\Mods\HostBrain\native\RonCompNative.log

УСТАНОВКА (только хосту; друзьям ничего ставить не нужно)
1. Закройте игру.
2. Запустите Install.bat. Он сам найдёт игру в Steam и поставит UE4SS и мод.
   Если Windows спросит про неизвестного издателя - «Подробнее» > «Выполнить в любом случае».
3. Запустите игру, создайте лобби и начните любую ко-оп миссию:
   на экране подготовки откроется меню «Выберите команду».
Остальные игроки выбирают сторону в чате: !swat или !suspect.

УДАЛЕНИЕ: Uninstall.bat.

Подробности и правила: https://github.com/VolkovIlia/ReadyOrNot-PvP


Ready or Not PvP - SWAT vs Suspects (ALPHA)
===========================================

This is an alpha: expect bugs. Please report them at
https://github.com/VolkovIlia/ReadyOrNot-PvP/issues
with the host's ue4ss\UE4SS.log and ue4ss\Mods\HostBrain\native\RonCompNative.log.

INSTALL (host only; friends need nothing)
1. Close the game.
2. Run Install.bat. It finds the game through Steam and installs UE4SS and the mod.
3. Start the game, host a lobby and start any co-op mission: the team menu opens on the
   pre-mission screen. Other players pick a side in chat: !swat or !suspect.
The in-game menu is in Russian for now.

UNINSTALL: Uninstall.bat.

Bundled: RE-UE4SS v3.0.1-1183-gcdbc0b66 (MIT, https://github.com/UE4SS-RE/RE-UE4SS, licence in game\ue4ss\LICENSE).
