Ready or Not PvP - SWAT vs Suspects (ALPHA)
===========================================

This is an alpha: expect bugs and crashes. Please report them at
https://github.com/VolkovIlia/ReadyOrNot-PvP/issues
Attach these files from the host's computer:
  <game folder>\ReadyOrNot\Binaries\Win64\ue4ss\UE4SS.log
  <game folder>\ReadyOrNot\Binaries\Win64\ue4ss\Mods\HostBrain\native\RonCompNative.log

INSTALL (host only; friends need nothing)
1. Close the game.
2. Run Install.bat. It finds the game through Steam and installs UE4SS and the mod.
   If Windows warns about an unknown publisher: "More info" > "Run anyway".
3. Start the game, host a lobby and start any co-op mission:
   the «ВЫБЕРИТЕ КОМАНДУ» (Choose a team) menu opens on the pre-mission screen.
Other players pick a side in chat: !swat or !suspect.
The in-game menu and messages are in Russian for now.

UNINSTALL: Uninstall.bat.

Details and rules: https://github.com/VolkovIlia/ReadyOrNot-PvP
