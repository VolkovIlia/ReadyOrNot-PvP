# RoN Competitive — мультиплеер в духе CS2 для Ready or Not

Мод добавляет в Ready or Not соревновательный режим «SWAT против подозреваемых» 5 на 5:
24 раунда до 13 побед, смена сторон, овертайм MR3, экономика и закупка как в CS2, бомба на точках A/B,
killfeed, таблица счёта, наблюдение за союзниками, боты и настройки хоста.
Вторая очередь — улучшения сети и сервера для обычного ко-опа.

## Как это устроено

- **Общий pak** (`ModKit/` → `/Game/Mods/RoNComp/`) ставят все игроки, в том числе через mod.io.
  В нём только ассеты: тонкие Blueprint-акторы с реплицируемым состоянием, виджеты, таблица предметов.
  Кода в pak нет.
- **HostBrain** (`HostBrain/`) — C++ мод для RE-UE4SS. Его ставит **только хост** (listen server).
  Все правила матча живут здесь. Клиенты получают состояние через штатную репликацию UE.
- **Чистое ядро** (`HostBrain/src/core`) не зависит от UE: фазы раунда, экономика, настройки в духе cvar.
  Покрыто юнит-тестами, собирается и проверяется вне игры.

Подробности: [docs/design.md](docs/design.md). Находки реверса: [docs/re-findings.md](docs/re-findings.md).
Тестирование: [docs/testing.md](docs/testing.md).

## Структура

```
docs/        дизайн, находки реверса, тестирование, матрица совместимости
re/          скрипты и экспорты REA (крупные дампы не коммитятся)
HostBrain/   src/core — чистое ядро, src/adapters — хуки UE4SS, tests/ — юнит-тесты
ModKit/      стаб-проект UE 5.3 для сборки общего pak
data/        competitive.cfg (настройки в духе cvar), items.csv, maps/*.json
tools/       сборка, деплой, запуск, проверка логов
```

## Быстрый старт

Сборка и тесты (MSVC):
```bash
powershell -File tools/build_hostbrain.ps1
```

Установка на хост (UE4SS + HostBrain):
```bash
powershell -File tools/install_ue4ss.ps1
```
```bash
powershell -File tools/deploy_ue4ss_mods.ps1
```

Игра с друзьями: хост создаёт лобби через меню «Игра по сети», друзья заходят, затем хост открывает консоль
(`~` или `F10`) и запускает режим — все переезжают на карту вместе (`servertravel`):
```
comp_start campus ff      нативный Firefight на Watt Community College (проверено)
comp_start campus RR_PVP  Defusal с бомбой (проверено; правила CS2 — этап 2)
comp_start <карта> <режим> force   непроверенная пара: может прервать игру у всех
comp_status               режим, счёт, защита, проверка попаданий
comp_maps / comp_modes    список карт и режимов
```
Из главного меню `comp_start` загружает карту в одиночном режиме — удобно для проверки, но друзья к этому не подключатся.

Одиночный матч за подозреваемых против ботов SWAT (из главного меню или из идущей миссии):
```
comp_play_suspect campus [n]  матч до n побед (по умолчанию 3): вы — подозреваемый, ИИ-подозреваемые — союзники,
                              отряд ИИ SWAT штурмует здание
comp_round_time 240 20        время штурма и подготовки, с (со следующего раунда)
comp_bot_hints 0|1            подсказка отряду после 60 с без контакта (по умолчанию включена)
comp_bot_accuracy 3           точность ботов SWAT: 1 = обычная, больше = хуже (по умолчанию 2)
comp_status                   счёт, раунд, фаза матча
comp_suspect off              выйти из режима
```
Как идёт раунд:
- Вас ставят к ИИ-подозреваемым и выдают случайное оружие: AK-102/103, SLR-47, Saiga-12, G3, FAL или дробовик плюс пистолет.
  Брони нет, как у подозреваемых.
- Подготовка 20 с, затем отряд SWAT идёт на штурм.
- Подозреваемые побеждают, если весь отряд нейтрализован или вы продержались время штурма (4 мин).
  SWAT побеждает, если вас убили, ранили до недееспособности, арестовали или вы сдались.
- После раунда миссия перезапускается сама, экран подготовки пропускается. Счёт и итоги показываются на экране.
- Боты не знают, где вы:
  - идут туда, где вас последний раз видели или слышали ваши выстрелы (в радиусе ~40 м);
  - без контакта зачищают здание комната за комнатой;
  - после 60 с без контакта отряд получает район в пределах ~15 м от вас, чтобы раунд не превратился в прятки.
- Сами по игроку-подозреваемому боты не стреляют: так устроены их правила огня. Поэтому HostBrain отдаёт тем, кто
  вас видит, короткие сценарные очереди (`ScriptedFireAtActor`).
- Внешне вы пока остаётесь бойцом SWAT: модель подозреваемого появится вместе с общим pak.

## Правовое

Мод не использует утёкшие исходники игры и не копирует код других модов.
Ассеты игры в репозиторий не попадают: дампы и распаковка лежат в `re/dumps`, `re/extract` и исключены из git.
